# Full-Stack Calculator API

A full-stack calculator built with **HTML, CSS, JavaScript, Node.js, and Express.js**. The frontend collects mathematical expressions and sends them to a REST API, where the backend evaluates the expression and returns the result as JSON.

## Features

- **Interactive Calculator UI** — Enter numbers, decimal values, and arithmetic operators.
- **REST API Integration** — Communicate with the backend using HTTP POST requests.
- **Backend Calculation Engine** — Performs calculations using a three-pass evaluation algorithm.
- **Operator Precedence** — Evaluates division and multiplication before addition and subtraction.
- **Input Validation** — Validates expression structure, numbers, and supported operators.
- **Error Handling** — Handles division by zero, invalid requests, and server connection errors.
- **JSON Communication** — Exchanges data between frontend and backend using JSON.

## Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm, which is included with Node.js
- A modern web browser

### 1. Clone the Repository

```bash
git clone https://github.com/Satyamtiwari23/full-stack-calculator-api.git
cd full-stack-calculator-api
```

### 2. Install Backend Dependencies

```bash
cd backend
npm install
```

### 3. Start the Backend Server

```bash
node server.js
```

The API will run at:

```text
http://localhost:3000
```

Expected terminal output:

```text
Calculator API running on port 3000
```

### 4. Launch the Frontend

Open `frontend/index.html` in your browser, or use the **Live Server** extension in VS Code.

Keep the backend server running while using the calculator.

## API Documentation

### Calculate Expression

**Endpoint:** `/calculate`

**Method:** `POST`

**Base URL:** `http://localhost:3000`

**Content-Type:** `application/json`

#### Request Body

```json
{
  "expression": [10, "+", 20, "*", 3]
}
```

#### Successful Response

```json
{
  "result": 70
}
```

#### Error Response

For division by zero:

```json
{
  "error": "Cannot divide by zero"
}
```

Invalid requests return an appropriate HTTP error status, such as `400 Bad Request`.

### Example API Request

You can test the API using `curl`:

```bash
curl -X POST http://localhost:3000/calculate \
  -H "Content-Type: application/json" \
  -d '{"expression":[10,"+",20,"*",3]}'
```

Expected response:

```json
{
  "result": 70
}
```

## Calculation Logic

The backend evaluates expressions using three passes:

1. **Division (`/`)** — Evaluates division operations first.
2. **Multiplication (`*`)** — Evaluates multiplication operations.
3. **Addition (`+`) and Subtraction (`-`)** — Evaluates remaining operations from left to right.

For example:

```text
Expression: 10 + 20 * 3

Pass 1: 10 + 20 * 3
Pass 2: 10 + 60
Pass 3: 70

Result: 70
```

The implementation uses array operations to replace each evaluated operation with its result.

**Current limitation:** Parentheses and advanced mathematical operations are not supported.

## How It Works

```text
User Input
    ↓
Frontend JavaScript
    ↓
Fetch API (HTTP POST)
    ↓
Express REST API
    ↓
Input Validation
    ↓
Calculation Engine
    ↓
JSON Response
    ↓
Frontend Displays Result
```

1. The user enters an expression using the calculator interface.
2. The frontend builds an expression array.
3. `fetch()` sends the array to the backend as JSON.
4. Express parses the request body and validates the expression.
5. The calculation engine evaluates the expression.
6. The backend returns the result as JSON.
7. The frontend reads the response and updates the display.
